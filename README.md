# Hextech Seekers · 海克斯捉迷藏

一个可以直接在浏览器运行的 3D 海克斯捉迷藏同人游戏。选择强化和英雄，在重建的峡谷下半区进行追逃。

**当前版本：0.3.0。单人对战 AI，支持 2–8 人配置；没有联网多人服务器。**

## 本地运行

安装 Node.js 20 或以上版本，无需安装任何 npm 依赖：

```bash
git clone https://github.com/xia-ke/Hextech-Seekers.git
cd Hextech-Seekers
node scripts/serve.mjs
```

浏览器打开 `http://localhost:8000`。也可运行 `npm start`。需要浏览器支持 WebGL2 并启用硬件加速。

`dist/` 是完整的静态网站，可交给任意支持 ES Modules 的静态 HTTP 服务部署。不要直接双击 HTML 使用 `file://` 打开。

## 已实现

- 云顶风格开局三选一、一次重掷，35 个海克斯变体。
- 12 名英雄：盖伦、阿狸、布里茨、拉克丝、提莫、费德提克、图奇、凯特琳、慎、劫、锐雯、亚索。
- 3D 跟随和倾斜峡谷镜头、旋转缩放、行走动画和技能效果。
- 地面与材质细节、流动水面、植被、营地、动态阴影、环境反射与画质切换。
- 统一的团队视野、战争迷雾、岩壁遮挡、草丛遮蔽；主场景、名字、小地图、点击目标及 AI 使用一致的可见性规则。
- 同阵营英雄和有效守卫共享视野；草内守卫才能探查草内。
- 图奇伪装与提莫隐形分开处理；控制守卫、扫描轮廓、临时试炼揭示及守卫压制。
- 准备 → 追捕 → 淘汰观战 → 积分结算 → 轮换追捕者。支持暂停、提前结束准备以及 3× 时间流速。

## 操作

| 操作 | 键位 |
| --- | --- |
| 相对镜头移动 | WASD / 方向键 |
| 点击地面行走、追踪可见敌人 | 鼠标右键 |
| 旋转 / 缩放镜头 | 拖动画面 / 鼠标滚轮 |
| 普通攻击抓捕 | 空格，或点击范围内敌人 |
| 英雄技能 | Q / E（E 需强化解锁） |
| 主动海克斯 / 放置守卫 | R |
| 第二召唤师技能 / 闪现 | Shift+D / F |
| 暂停 | Esc |

手机提供方向与技能按钮。右上角可以选择「精致」或「流畅」画质。Shift+D 用于避免召唤师技能与 WASD 的 D 冲突。

## 视野说明

没有当前视野的地形会变暗，已探索区域不会因此永久亮起。敌方英雄在视野外、墙后和未被探查的草丛中隐藏；不会保留名字或小地图上的实时位置。队友位置仍可见。

扫描器给出隐藏敌人的轮廓，不提供可攻击目标，也不会自动照亮周围地形。控制守卫可以侦测伪装，但不能看穿提莫的隐形。淘汰后沿用己方视野观战。具体边界、范围和适配见 [docs/vision.md](docs/vision.md)。

## 项目结构

```text
dist/
  index.html       游戏界面
  style.css        样式与移动端布局
  data.js          英雄、海克斯、营地、草丛和岩壁配置
  game.js          对局、AI、技能、输入和积分
  vision.js        共享视野、遮挡、草丛、侦测与雾区数据
  rift3d.js        英雄、地形、镜头与场景渲染
  graphics.js      材质、环境与战争迷雾后处理
  assets/          本地图像
  vendor/          Three.js 与许可证
scripts/serve.mjs  无依赖的本地静态服务
tests/            对局、视野及渲染状态检查
docs/             规则与交接说明
```

## 验证

```bash
node --test
```

也可运行 `npm test`。测试覆盖海克斯与阵营组合、完整 AI 回合、抓捕与计分、视野范围、岩壁、草内/草外守卫、隐形/伪装、团队共享、观战以及隐藏模型/名字/点击目标。

测试不包含真实浏览器或 GPU 的画面验收；渲染集成测试仅替换了 GPU 和 DOM。开始使用前，建议在目标设备实际运行一局。

## 适配范围

这是规则驱动的同人小游戏，不是英雄联盟客户端复刻。英雄模型根据特征重新制作，地形与技能使用简化实现；无法等同端游原版资产、战斗系统或全部视野例外。提供的规则引用了 `符文.png`，但附件中缺少该图，因此没有臆造默认符文页。已明确的海克斯规则按 [docs/rules.md](docs/rules.md) 说明实现。
