# 视野与战争迷雾

## 行为

同阵营存活英雄与有效守卫组成视野源。普通视野需要同时满足范围、岩壁不遮挡、目标草丛可探查三个条件。草外的英雄或守卫不能探查草内，即使二者距离很近。当前版本每片草丛为独立圆形区域，岩壁为与移动碰撞对齐的椭圆区域。

视野外地形暗化；敌方单位的模型、名字和小地图标记直接隐藏，并从鼠标拾取、普通攻击与指定目标技能的合法目标中排除。AI 调用同一套判定。观战保留自己阵营的共享视野，不切换为全知视角。

## 例外

- 图奇 Q 为伪装：普通守卫不能直接看穿，附近敌方英雄或控制守卫可侦测；仍须满足正常地形与草丛视野条件。
- 提莫 Q / 静止被动为隐形：靠近或控制守卫不能直接揭示。
- 神谕扫描显示附近隐藏敌人的红色轮廓，该轮廓不提供名字、小地图标记或可攻击目标，不扩展普通地形视野。
- 凯特琳试炼的陷阱 / 绳网会给命中目标施加该阵营可见的 8 秒揭示。这是捉迷藏试炼适配，并非逐项复制端游 E 的机制。
- 控制守卫和扫描可压制范围内普通敌方守卫，控制守卫自身不会被压制。基础捉迷藏规则不提供摧毁守卫的操作。
- 卡牌感应仅提供营地级线索；AI 也不会借此获得目标的精确坐标。

## 实现

`VisionSystem` 负责即时判定，`VisionField` 将同一判定采样到 192×192 的团队雾区网格。岩壁使用线段与椭圆相交测试，草丛单独判定。雾区边缘仅在显示时做窄范围平滑；英雄能否出现、被选取和抓捕仍使用即时判定。

3D 场景先输出颜色和深度，再用深度重建世界坐标，在后处理中采样雾区。小地图采样同一个字段。动态效果在没有地形视野的位置被裁掉。雾区按约 70 ms 更新；大幅位移会触发立即更新。每回合清除探索历史。

这是本地单人模拟，所有状态保存在当前浏览器内，不包含多人服务器的网络层反作弊或信息隔离。
