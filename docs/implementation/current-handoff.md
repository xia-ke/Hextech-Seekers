## V1 规则不可回归

- 单机玩家对 AI；2–4 个角色，一名追捕者，英雄不重复；玩家自行选择追捕/躲藏。
- 准备阶段 120 秒；有效**追捕者普攻接触帧**触发抓获。技能命中不得直接抓获；被抓者进入观战。
- 追捕者准备期不可移动/施法（以实际规则和测试为准）；躲藏者之间不能共享全图视野，草丛、墙体、战争迷雾按当前原生基线继续完善。
- 海克斯为每名角色独立三选一；冻结（金）2 秒眩晕，星体结界（银）5 秒仅英雄技能沉默，镜花水月（银）挡第一次抓捕并短暂免捕；时光发条只修改结束时间，不改提前全抓加分门槛。
- 不添加兵线、防御塔或默认召唤师技能；野怪不攻击、不死亡，但可作为合法技能交互目标（必须使用核验过的营地/生成位置）。

规则冲突时首先检查 `docs/implementation/v1-rules.md` 与原生对应阶段文档，并新增回归测试，不能凭推测修改既定约束。

## 尚未完成，不得声称完成

1. 布里茨、锐雯、亚索的原始模型/纹理/骨骼动画没有随 Git 仓库发布；只有额外、合法来源并完成哈希验证/导入才可以展示为原始模型，缺失时明确使用战术标记。
2. 原始技能特效、源动画事件时间点、英雄视觉尺度/朝向/材质和 Unity 画面人工视觉验收仍是独立待办。
3. Phase 15 尚未覆盖所有目标依赖型技能/连续重施的实际 Windows Player 交互（例如亚索 E 的真实目标冲刺、锐雯 Q 连续三段）。
4. 只有通过技术 QA 才能说技术通过，不能据此声称“完全还原英雄联盟视角/视野/画质”或“完整成品可发布”。
5. 版权、第三方来源许可、Unity 授权与重新分发资格必须单独核实；不得将原游戏素材直接打包公开发行。

## 建议下一开发切片：Phase 16（优先）

**目标：为 Phase 15 未覆盖的目标依赖/连段技能补充确定性的真实 Windows Player QA**，仅新增有依据的测试和必要的最小机制修复，避免大规模美术重构。

具体实施：
1. 阅读 `native-unity/docs/phase-15-real-player-skill-regression.md`，定位 `NativeMatchController.TryHumanSkill`、真人输入状态机、技能状态类与 `-hextechGameplayQA` 测试入口。
2. 在真实 Map11 可走网格上布置**可见、合法、可验证**的目标，验证亚索 E 目标限制、冲刺路径与同一目标复用锁；分别加入合法与非法目标。
3. 对锐雯 Q1/Q2/Q3 逐次施放，检查各段连招窗口、最终控制生效、路径扫掠合法性、窗口超时回到 Q1；整个过程不直接触发捕获。
4. 覆盖准备期/沉默/眩晕/抓获后状态、分阵营和视野限制；从真实控制器入口测试，不以直接写状态字段代替技能施放。
5. 在 `gameplay-result.json` 中输出每条案例的可审计证据（技能、阵营、施法前后时钟、角色状态、目标状态、合法性判定、失败原因），并在 Windows CI 中以缺失或失败证据作为失败条件。
6. 补充 EditMode 定向回归、完整已有 Unity Editor 测试、静态检查和真实 Windows GPU Player QA。只在真实跑过后记录确切通过数、CI run URL 和截图，不预填 PASS。
7. 不更新旧网页游戏以掩盖原生缺口，不删除已验证历史素材/证据，不强推 `main` 或覆盖他人的新增提交；代码变更优先独立分支 + PR。
