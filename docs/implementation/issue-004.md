# Issue 004 — 独立视线与 AI 感知管线（基础版）

日期：2026-10-31。状态：**PARTIAL**。这不是《英雄联盟》本体完全复刻的视野，也不是可玩 AI 对局。

## 本阶段已实现
- 新增 `dist/rebuild/vision-baseline.js`，按每个观察者独立检查目标：范围限制、原始地图 walkable 网格阻挡、保守的对角转角遮挡、草丛 ID 隐藏。没有共享躲藏者的发现结果，不做敌人位置缓存或全局透视。
- `dist/rebuild/app.js` 在地图加载后向诊断模块提供与当前导航实例相同的原始 walkable/bushes 数据及网格映射，复用地图原始坐标。
- `dist/rebuild/round-lab.js` 把视线检测回调传入 `chooseAiDestination`；AI 仅在本人视野内发现敌人时才能尝试追逐／逃离，否则按给定巡逻点移动。面板显示每个观察者视野内的敌人，导航演练 5 秒推进与准备／追捕状态同步；手动模拟抓获同步淘汰相应导航实体。

新增 `tests/vision-baseline.test.mjs` 共 8 项：距离边界、墙体、斜角挡墙、草丛内外、不同草丛分组、独立躲藏者、阻挡下禁止 AI 追击与无遮挡追击。使用 JavaScript 执行环境从 GitHub 拉回代码并执行现有 14 项＋新增 8 项，**22/22 PASS**。此环境仍未能运行真实 Chromium 全页面与完整 Node 文件测试，不将独立单元测试视作游戏画面验收。

## 明确限制
- 原本《英雄联盟》视野机制涉及专有的地形、草丛视觉属性、遮挡边界、单位半径、显形与其他例外。本阶段只用网格 walkable 和草丛 ID 建立保守基线，**不能声称与 LoL 本体完全一致**。部分不可通行单元并不代表视觉上完全挡住，反之亦然；必须后续核查专用 vision blockers。
- 当前 `canSee` 尚未用于实际战斗界面隐藏英雄、名字、小地图信息或攻击选取。诊断面板为开发者工具，能显示内部逻辑坐标，不是面向正式玩家的信息泄露模型。
- 真实英雄模型仍仅有盖伦，玩家的真实 A 键仍为动画预览。AI 追逃当前限规则诊断模块，没有真正运行整局、自动普攻或真实击中事件；没有野怪／技能／八条强化。
- 没有在本回合同步 Sites 站点；Issue 001 视觉／性能硬验收、Issue 002/003 的真实游玩仍保持 PARTIAL。
