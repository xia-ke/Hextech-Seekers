# 规则适配

依据用户提供的《海克斯捉迷藏.txt》和《海克斯.docx》实现。

- 2–8 人；1 名初始追捕者，其余为躲藏者。AI 补齐所有非人类玩家。
- 范围限定峡谷下半区野区与河道。准备时间 2 分钟；追捕时间为 `3 + 2 × (躲藏者人数 − 1)` 分钟。
- 追捕者默认仅近战英雄，普攻命中完成抓捕；躲藏者不能普攻追捕者。海克斯征召和英雄试炼可覆盖基础限制。
- 抓捕后失去资格并返回泉水；每名玩家轮流担任追捕者后结算总积分。
- 假设初始躲藏者 N 人，最终幸存 S 人。S > 1 时每名幸存者得 S 分，被捕者 0 分；S = 1 时该幸存者得 `ceil(N/2)` 分，其余被捕者各 1 分；S = 0 时躲藏者均 0 分。追捕者得 N − S 分，在 `3 + 2 × (N − 2)` 分钟内抓完全部目标额外 +1 分。
- 主动强化默认一次；星体结界按明确的 2 分钟冷却可重复施放；窃法巧手·金给予的强化仍限一次。
- 净水监狱·金全局禁用其他海克斯；禁用期间不获得征召例外。阵营交换在开局结算一次，时长设为 3 分钟。
- 装备、符文或小兵前置步骤自动转为效果：鞋子加速、技能急速减少冷却、升级咯解锁第二技能、守护者提供短暂保护。
- 默认符文图没有随附件提供，因此默认符文页暂缺。仅实现文档明确指定的效果。
- 幽魂监牢与静谧面纱自动确定目标，在开局展示说明。银色时光发条由躲藏者使用时延长、追捕者使用时缩短。
- 普通守卫每局 3 次，控制守卫按规则 2 次；保留不可主动破坏道具的限制。
- 诺克萨斯角斗场为简化的 3 点生命决斗，进入后没有计时限制。技能抓捕例外改为单次命中扣 1 点生命。
- 英雄技能只保留本玩法需要的位移、控制、保护、隐匿与侦查，并非完整英雄技能复刻。
- 海克斯详细数据和描述均位于 `dist/data.js`，游戏内「玩法规则」含完整图鉴。
